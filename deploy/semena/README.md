# Семена - Агент

Корпоративное Windows-приложение на базе форка OpenCode для работы сотрудников с локальной моделью через защищенный шлюз `10.1.50.101`.

## Стабильная версия

Стабильное состояние зафиксировано 2026-08-27.

- Клиент: `Семена - Агент`.
- Видимое имя модели в UI: `Семена Агент`.
- Технический model id: `semena/semena-qwen36`.
- Runtime: FreeToken на `10.1.50.101:1919`, наружу только через TLS gateway `https://10.1.50.101:8443/v1`.
- Контекст: `57344` токена, output: `4096`.
- Включены MCP: `semena_1c` и `semena_image`.
- Старые пользовательские модели и старые локальные бэкапы установки не являются частью стабильного контура.

## Состав

- Нативное Desktop-приложение с отдельным профилем и конфигом.
- Авторизация сотрудника через корпоративную веб-панель и персональный API key.
- Единственный включенный провайдер OpenCode: `semena`.
- Единственная клиентская модель: `semena-qwen36`, отображается как `Семена Агент`.
- 1С-инструменты подключаются через уже работающий MCP-сервер `http://10.1.50.40:3000/sse`.
- Инструменты изображений подключаются через MCP-сервер `http://10.1.50.40:3003/sse`.
- Доступ к внешним директориям остается через явное разрешение пользователя.

## Установка

Пользователь скачивает один файл:

```text
http://10.1.50.101:3010/downloads/Semena-Agent-Setup-x64.exe
```

Внутри установщика находятся Desktop-инсталлятор, сертификат, конфиг и `AGENTS.md`. Пароль не сохраняется; после проверки создается персональный ключ.

## Проверка

```powershell
python -m unittest deploy.semena.tests.test_platform
```

Для проверки MCP:

```powershell
$env:XDG_CONFIG_HOME = "$env:LOCALAPPDATA\Семена - Агент\config"
$env:XDG_DATA_HOME = "$env:LOCALAPPDATA\Семена - Агент\data"
$env:XDG_CACHE_HOME = "$env:LOCALAPPDATA\Семена - Агент\cache"
bun run packages\opencode\src\index.ts mcp list
```

Ожидаемый результат: `semena_1c connected` и `semena_image connected`.
