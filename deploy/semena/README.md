# Семена - Агент

Корпоративное Windows-приложение для работы сотрудников с локальной моделью на
`10.1.50.101`. У каждого пользователя отдельная авторизация, а файлы проекта
остаются на его компьютере.

## Состав

- нативное Desktop-приложение с отдельным идентификатором и профилем;
- вход по e-mail и паролю корпоративной веб-панели;
- персональные отзываемые ключи в auth-service;
- TLS и ограничение запросов на nginx;
- единственный доступный провайдер и модель `Семена Code`;
- изоляция от уже установленного стороннего приложения.

## Установка для сотрудника

Инструкция и архив опубликованы во внутренней сети:

- `http://10.1.50.101:3010/agent.html`;
- `http://10.1.50.101:3010/downloads/SemenaAgentSetup.zip`.

Пользователь распаковывает ZIP и запускает `Установить Семена - Агент.cmd`. В корне
архива также лежит `Прочти меня - установка.txt`; технические файлы убраны в папку
`Служебные файлы`. Установщик
на русском языке запрашивает e-mail и пароль веб-панели, проверяет их по TLS,
получает персональный ключ, проверяет SHA-256 Desktop-установщика и запускает
установку. Пароль не сохраняется.
